ESP32-CAM installer

Install the camera firmware without compiling it. Use a desktop browser with Web Serial support, such as Chrome or Edge, over HTTPS or localhost.

  1. Connect your USB-to-UART bridge using 3.3 V logic and a common ground. Supply the camera at its 5V pin.
  2. Connect GPIO0 to GND, then reset the camera to enter download mode. Close other serial monitors.
  3. Select an operation below. For device settings, generate a private config.bin from your wifi.toml using the supplied script.
  4. Click Connect, choose the serial port, and follow ESP Web Tools. Leave Erase device unchecked to retain settings during updates.
  5. After flashing, remove GPIO0 from GND and press RESET. Open Logs & Console to read the camera's DHCP address, then visit that address.

Your configuration file is read locally in this browser and sent to the camera through the serial port. This page does not upload it to a server. Keep it private: it contains Wi-Fi credentials.

Erasing the entire device removes settings. A device with no valid settings stays idle and reports how to flash config.bin; it does not start an access point or an Improv Wi-Fi setup wizard.

Select a config.bin to install firmware and settings.

Configuration generation: python tools/wifi_config.py wifi.toml config.bin (Python 3.11+ and esp-idf-nvs-partition-gen). A config-only install requires the matching camera firmware/partition layout.
